Pixel Forge provides local image and video pixelation plus a frame-based game-asset workspace.

Download the `.dmg` for Apple Silicon (`aarch64`) or Intel (`x64`) macOS, or the `x64-setup.exe` installer for Windows. See [installation instructions](https://github.com/ooberguts/pixel-forge/blob/main/docs/INSTALL.md).

Installed release builds check for signed updates on startup and every six hours. Updates install when you choose **Install & restart** in App settings.

This early release is ad-hoc signed on macOS and unsigned on Windows. Operating systems may show an unidentified-publisher warning. Video encoding needs a separate FFmpeg installation; PNG and sprite-sheet exports work without FFmpeg.
